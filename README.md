

# Impulse Project Update

The Impulse project transitioned to several closed-source, commercial products under the Impulse umbrella.

### NextSignal
Threat detection layer that integrates with your existing SIEM or Elastic setup to add deep host telemetry and AI to the monitoring stack.

### vmLock
Configuration hardening and baseline enforcement framework that continuously validates OS, service, and file-level settings to lock down cloud VMs, prevent configuration drift, and reduce attack surface—before attackers can exploit it.

### Impulse XDR
A complete host security management solution for cloud infrastructure.
